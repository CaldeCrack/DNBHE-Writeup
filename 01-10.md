# Levels 1-10

## [Level I](https://donotbelieveherlies.nekoweb.org/Dnbherl/thefirsttime.html)

Inspecting the source code there are some comments but nothing too useful.

The video itself seems to be communicating some morse code but the only problem is that there is no spacing between words, still I got the following code:

......-...--.--.

The other hint that ties this problem is the number displayed in the video itself, if its not too recognizable the same number is used as the file name for it, which is 414421.

Using those numbers as the length of each word for the morse code gives the solution when translating it:

<details>
  <summary>Click to reveal solution</summary>
  .... . .-.. .--. -- . = HELPME
</details>
