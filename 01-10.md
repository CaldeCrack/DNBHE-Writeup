# Levels 1-10

## [Level I](https://donotbelieveherlies.nekoweb.org/Dnbherl/thefirsttime.html)

Inspecting the source code there are some comments but nothing too useful.

The video itself seems to be communicating some morse code but the only problem is that there is no spacing between words, still I got the following code:

......-...--.--.

The other hint that ties this problem is the number displayed in the video itself, if its not too recognizable the same number is used as the file name for it, which is 414421.

Using those numbers as the length of each word for the morse code gives the solution when translating it:

<details>
  <summary>Click to reveal solution</summary>
  .... . .-.. .--. -- . = HELPME
</details>

With that hint I first tried editing the brightness, turning it up revealed the code in the figure:

## [Level III](https://donotbelieveherlies.nekoweb.org/Dnbherl/adarkshadow.html)

We have another tutorial comment saying that we should try and get another file not directly displayed in the page, specifically a `.jpg`, which exists, so we download the file.

It also says that the file could have more information if we know were to look at, so I tried with the metadata.

The only thing that stood out to me was the author, since it was just a big number: 1106639990879.

After a lot of tinkering, doing things like trying to get a word from this alone using some encryption, for example using the magic option from [CyberChef](https://cyberchef.io) it was thinking it was a timestamp so I tried a lot of date formats as the code but nothing worked.

Finally, I thought that maybe I should try to reverse it considering that in the video the image is being horizontally mirrored, initially I didn't get anything until I searched in Google the reversed number, which gave me a book in all of the results.

I was wondering why and that's when I discovered that it was because of something called the ISBN (International Standard Book Number), and that clicked since the filename was NBSI which is ISBN reversed.

With that I got the solution which was the name of the book:

<details>
  <summary>Click to reveal solution</summary>
  In The Night
</details>

## [Level IV](https://donotbelieveherlies.nekoweb.org/Dnbherl/inthenight.html)

In this level the comment hints towards using Audacity, so I download the file and get just its audio to use it in the program.

The most notable thing is a pattern in a section of the right channel, using a spectrogram we can see some clear braille.

But trying to just make a 1-to-1 translation doesn't work since the third character doesn't exists, in which case we use the filename as a hint that leads us towards inverting the code.

In this case that means that for each two vertical slices, which represent one braille character, the places where is a dot in reality its an empty space and viceversa, also for some particular cases that only have one vertical line, in reality there's two of them but the one we don't see its a full one, considering the spacing we notice that all of them are before the shown one, finally giving us the answer:

<details>
  <summary>Click to reveal solution</summary>
  creepingandcackling
</details>
